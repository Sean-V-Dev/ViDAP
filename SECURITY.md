# Security Policy

## Supported versions

ViDAP has no released or supported product version yet. The repository is in
its foundation stage, so this policy describes reporting rather than a support
or remediation commitment.

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. Do not place exploit
details, credentials, personal data, or other sensitive evidence in a public
discussion.

Use GitHub's private vulnerability-reporting form for ViDAP:

<https://github.com/Sean-V-Dev/ViDAP/security/advisories/new>

Please provide a concise description, affected area and version or commit when
known, reproduction conditions, the likely impact, and a safe way to contact
you. Share only the information needed to assess the report safely.

## Ordinary reports

For non-sensitive bugs, documentation problems, and feature proposals, use
[GitHub Issues](https://github.com/Sean-V-Dev/ViDAP/issues). Do not use an
Issue for a suspected vulnerability.
